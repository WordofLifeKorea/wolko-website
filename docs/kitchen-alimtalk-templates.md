# 주방 보조 알림톡 템플릿

차량 스케줄 알림톡과는 **별개**의 템플릿이고, 검수는 **한 개**만 받으면 됩니다.
칸 이름은 변수 `#{업무}`로 들어갑니다(예: `점심 준비`, `점심 클린업`, 한 사람이 둘 다 맡으면 `점심 준비·클린업`).

## 템플릿 본문 (솔라피에 그대로 등록)

```
#{담당자}님은 #{날짜} #{업무} 담당자 입니다.
식사 시간은 #{시간}입니다. 주방 보조 스케줄에서 일정을 확인해 주세요.
```

| 변수 | 들어가는 값 |
|---|---|
| `#{담당자}` | 신청한 사람 이름 (기존 승인 템플릿과 같은 변수명) |
| `#{날짜}` | `10/7 수` |
| `#{업무}` | `아침 준비` · `아침 클린업` · `점심 준비` · `점심 클린업` · `저녁 준비` · `저녁 클린업` · `점심 준비·클린업` 등 |
| `#{시간}` | 식사 시간, 예: `오후 12:30` |

- 버튼(선택): 웹링크 버튼, 이름 `스케줄 확인`, 링크 `https://wolko.org/kitchen/`
- `#{담당자}님은 …` 형태로 수신 대상을 분명히 했습니다(예전 `#{이름}`은 반려됨).
- 변수 때문에 반려되면 알려 주세요. 칸별 템플릿(`KAKAO_TEMPLATE_KITCHEN_LUNCH_PREP` 등)으로 바꾸는 방법도 있습니다.

문자(알림톡 실패 시) 문구: `[WOLKO 주방] 가나다님, 10/7 수 점심 준비 담당입니다. 식사는 오후 12:30입니다. 일정: wolko.org/kitchen` (한글 90바이트를 넘어 솔라피가 자동으로 장문(LMS)으로 보냅니다)

## 켜는 방법

1. 솔라피에서 위 템플릿을 등록·승인받습니다. 승인 전에는 자동으로 문자만 나갑니다.
2. Cloudflare Pages 환경변수 `KAKAO_TEMPLATE_KITCHEN`에 승인된 템플릿 코드를 넣고 재배포합니다.
   (`KAKAO_PF_ID`, `SOLAPI_*`는 차량과 같은 값을 그대로 씁니다.)
3. 인증키는 `KITCHEN_REMINDER_SECRET`(없으면 `DRIVE_REMINDER_SECRET`, 그것도 없으면 `CRS_REMINDER_SECRET`)을 쓰므로 새로 만들지 않아도 됩니다.
4. GitHub Actions의 **Kitchen reminders**를 `dry_run=true`로 실행해 계획을 확인한 뒤, 시험 발송은 `test_phone`에 본인 번호를 넣어 실행합니다.
5. 문제가 없으면 저장소 Actions Variable `KITCHEN_REMINDERS_ENABLED=true`로 자동 발송을 켭니다.

## 발송 시각

식사 시간 **1시간 전**에 그 끼니를 신청한 사람에게 보냅니다. 식사 시간은 주방 보조 페이지의 **시간·인원**에서 바꿉니다
(주방 관리자·마스터만, 30분 단위, 기본 아침 9:00 · 점심 12:30 · 저녁 17:00 → 알림 8:00 · 11:30 · 16:00).
한 사람이 같은 끼니의 준비와 클린업을 둘 다 신청했으면 한 번만 보냅니다. 같은 날 같은 사람·같은 끼니에는 한 번만 보내고,
알림 시각 이후에 신청한 사람과 식사 시간이 지난 뒤에는 보내지 않습니다.
