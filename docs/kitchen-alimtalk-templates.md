# 주방 보조 알림톡 템플릿

차량 스케줄 알림톡과는 **별개**의 템플릿입니다. 칸(업무)마다 템플릿이 하나씩, 모두 6개입니다.
변수는 기존에 승인된 템플릿과 같은 `#{담당자}`(신청한 사람 이름), `#{날짜}`(예: `10/7 수`) 두 개만 씁니다.

## 템플릿 문구 (솔라피에 그대로 등록)

| 칸 | 환경변수 | 본문 |
|---|---|---|
| 오전 준비 | `KAKAO_TEMPLATE_KITCHEN_AM_PREP` | `#{담당자}님은 #{날짜} 오전 준비 담당자 입니다.` |
| 오전 클린업 | `KAKAO_TEMPLATE_KITCHEN_AM_CLEAN` | `#{담당자}님은 #{날짜} 오전 클린업 담당자 입니다.` |
| 점심 준비 | `KAKAO_TEMPLATE_KITCHEN_LUNCH_PREP` | `#{담당자}님은 #{날짜} 점심 준비 담당자 입니다.` |
| 점심 클린업 | `KAKAO_TEMPLATE_KITCHEN_LUNCH_CLEAN` | `#{담당자}님은 #{날짜} 점심 클린업 담당자 입니다.` |
| 저녁 준비 | `KAKAO_TEMPLATE_KITCHEN_DINNER_PREP` | `#{담당자}님은 #{날짜} 저녁 준비 담당자 입니다.` |
| 저녁 클린업 | `KAKAO_TEMPLATE_KITCHEN_DINNER_CLEAN` | `#{담당자}님은 #{날짜} 저녁 클린업 담당자 입니다.` |

- 본문 아래에 한 줄을 더 넣고 싶으면: `주방 보조 스케줄에서 일정을 확인해 주세요.` (선택)
- 버튼(선택): 웹링크 버튼, 이름 `스케줄 확인`, 링크 `https://wolko.org/kitchen/`
- 수신 대상이 분명하도록 `#{담당자}님은 …` 형태를 유지했습니다(예전 `#{이름}`은 반려됨).
- 칸 이름을 변수로 넣지 않고 칸마다 템플릿을 따로 만들었습니다(문구가 고정이라 검수가 단순합니다).

문자(알림톡 실패 시) 문구: `[WOLKO 주방] 가나다님은 10/7 수 점심 준비 담당자 입니다. 주방 보조 스케줄: https://wolko.org/kitchen/#2026-10-07`

## 켜는 방법

1. 솔라피에서 6개 템플릿을 등록·승인받습니다. 템플릿이 아직 없는 칸은 자동으로 문자만 나갑니다.
2. Cloudflare Pages 환경변수에 위 표의 `KAKAO_TEMPLATE_KITCHEN_*` 6개를 승인된 템플릿 코드로 넣고 재배포합니다.
   (`KAKAO_PF_ID`, `SOLAPI_*`는 차량과 같은 값을 그대로 씁니다.)
3. 인증키: `KITCHEN_REMINDER_SECRET`(없으면 `DRIVE_REMINDER_SECRET`, 그것도 없으면 `CRS_REMINDER_SECRET`)을 쓰므로 새로 만들지 않아도 됩니다.
4. GitHub Actions의 **Kitchen reminders**를 `dry_run=true`로 실행해 계획을 확인한 뒤, 시험 발송은 `test_phone`에 본인 번호를 넣어 칸을 골라 실행합니다.
5. 문제가 없으면 저장소 Actions Variable `KITCHEN_REMINDERS_ENABLED=true`로 자동 발송을 켭니다.

## 발송 시각

주방 보조 페이지의 **알림 시간**에서 칸마다 바꿉니다(주방 관리자·마스터만, 30분 단위, "보내지 않음" 가능).
기본값은 임의로 잡은 값입니다 — 오전 준비 7:00 · 오전 클린업 9:00 · 점심 준비 10:00 · 점심 클린업 13:00 · 저녁 준비 15:00 · 저녁 클린업 18:30.
같은 날 같은 칸에는 한 번만 보내고, 발송 시각 이후에 신청한 사람에게는 보내지 않습니다.
