# 평가 설문 — 설명서와 알림톡 문안

## 1. Ella 를 위한 사용법 (캠프 준비 → 평가 설문)

1. **설문 만들기**를 누르고 **누구에게 보내는지** 고릅니다 (스태프 / 학생 / 부모님 / 교회·학교 / 기타). 고른 대상에 맞는 시작 질문이 먼저 들어가요. 저장해 둔 템플릿에서 시작할 수도 있어요.
2. 설문 머리글(제목·설명)과 질문 카드가 보여요. **카드를 누르면** 그 카드를 고칠 수 있어요(왼쪽에 파란 줄이 생겨요).
   - 질문 내용, 질문 종류(짧은 글 · 긴 글 · 객관식 · 체크박스 · 드롭다운 · 선형 배율 1~5/1~10 · 별점), **필수** 켜기·끄기, 복사, 삭제, 위·아래 이동.
   - 객관식·체크박스·드롭다운은 보기를 더하고 지울 수 있어요. 객관식·체크박스에는 「기타(직접 쓰기)」도 넣을 수 있어요.
   - 모든 글은 한국어/English 두 칸이에요. 한쪽만 적고 **✨ AI로 영어 채우기**를 누르면 비어 있는 쪽을 채워 줘요(설문 문구만 AI에 가요. 꼭 읽고 고쳐 주세요).
   - **+ 제목·설명**은 질문 사이에 구역 제목이나 안내 글을 넣어요(답은 없어요).
3. **미리보기**로 답하는 사람이 보는 모습(한국어/English)을 확인하고, **저장**하세요.
4. 목록에서 **링크 켜기** → 링크를 복사해서 직접 보내거나, **설문 보내기**로 카카오톡 알림톡을 보내요.
5. **결과 보기**: 별점·배율은 평균과 막대, 객관식·체크박스·드롭다운은 개수와 %, 글은 목록으로 보여요. 이름·연락처는 어디에도 남지 않아요(익명).

질문을 고치거나 순서를 바꿔도 **이미 받은 답은 같은 질문에 그대로 붙어 있어요.** 질문을 지우면 그 질문의 옛 답은 결과 화면에서 사라져요(데이터는 남아 있어요).

### 설문 보내기 (알림톡)
- **받는 사람 확인**: 먼저 몇 명에게 가는지와 가려진 예시(홍*동 · 010-****-1234)만 보여 줘요. 이 단계에서는 **아무것도 보내지 않아요.**
- **한 번 더 확인**: 「학생(캠퍼) 24명에게 설문을 보낼까요?」에서 **보내기**를 눌러야 실제로 가요.
- 같은 번호에는 같은 설문이 **한 번만** 가요(번호 자체는 저장하지 않고, 되돌릴 수 없는 해시만 남겨요). 실패한 번호는 다시 보낼 수 있어요.
- 하루(24시간) **300통** 한도(포털 전체 합계)를 넘으면 아무에게도 보내지 않아요. 한 번에 최대 100통씩 보내고, 남으면 「남은 N명에게 이어서 보내기」를 눌러요.
- 누가 받나요?
  | 대상 | 받는 사람 |
  |---|---|
  | 학생(캠퍼) | **접수된 모두(예비 대기자 제외)** — 접수 대기·예약금·확정 모두 포함. 단체 신청은 담당자 한 분 |
  | 부모님 | 신청서의 비상연락처·보호자 칸에 적힌 글에서 뽑은 휴대폰 번호 + 크루 지원서의 보호자 번호. **최선의 방법이에요** — 글에서 뽑는 것이라 틀리거나 빠진 번호가 있을 수 있어요 |
  | 스태프 | 스태프·크루 지원자 중 **수락된 사람**(지원만 하고 수락되지 않은 사람은 제외) |
  | 교회·학교 | 연락처 화면의 교회·학교 중 번호가 있는 곳 — **보내는 사람이 직접 골라요** |
  | 기타(링크만) | 보내는 기능 없이 링크만 복사해서 직접 전해요 |
- **알림톡 템플릿이 아직 없으면 보내지 않고**, 「링크 복사」로 직접 보내라고 안내해요.
- 카카오톡을 받을 수 없는 번호는 솔라피 설정에 따라 **문자로 대신 갈 수 있어요**(신청 안내와 같은 방식). 확인 창에 이 내용이 적혀 있어요.

## 2. 솔라피/카카오에 제출할 알림톡 템플릿 문안(제안)

- 템플릿 이름 예: `캠프 평가 설문 안내`
- 메시지 유형: 기본형(텍스트). 강조 표기·부가 정보는 쓰지 않아도 돼요.
- **변수는 정확히 이 세 개**여야 해요(코드가 이 이름으로 보내요): `#{이름}` `#{설문명}` `#{링크}`

```
#{이름}님, 안녕하세요. 월코 캠프 & 아웃리치 팀입니다.

함께해 주셔서 감사합니다. 다음 캠프를 더 잘 준비하기 위해 짧은 평가 설문을 부탁드려요.

▶ 설문: #{설문명}
▶ 소요 시간: 약 3분
▶ 이름·연락처는 묻지 않고, 답은 익명으로 저장돼요.

아래 링크에서 참여해 주세요.
#{링크}

문의: 010-7310-9216 · wolkorea1@gmail.com
```

- 본문에 링크 변수를 넣는 문안이 심사에서 거절되면, 같은 문안에서 `#{링크}` 줄을 빼고 **웹링크 버튼**(버튼 이름 `설문 참여하기`, 주소 `#{링크}` 변수)으로 다시 신청해 보세요. 코드는 `#{링크}` 변수에 전체 주소를 넣어 보내요.
- 설문 요청이 「광고성」으로 분류되면 정보성 템플릿으로 승인되지 않을 수 있어요. 솔라피 담당자에게 서비스 이용 후 만족도 조사로 분류되는지 확인해 보세요.
- 승인되면 Cloudflare 변수 **`KAKAO_TEMPLATE_SURVEY`** 에 템플릿 코드를 넣어요(이미 있는 `SOLAPI_API_KEY` · `SOLAPI_API_SECRET` · `KAKAO_PF_ID` 도 필요해요). 코드는 한 줄도 바꾸지 않아도 돼요.
- 카카오톡을 받을 수 없을 때 대신 가는 문자 문구(코드에 들어 있음): `[월코] OOO님, (설문명) 설문에 참여해 주세요. 이름·연락처는 묻지 않아요.` + 링크

## 3. 운영 메모 (개발·관리자용)

- DB: `camp-team/db/0034_survey_builder.sql` (surveys 에 `audience` · `description` · `descriptionEn` · `qSeq` 추가, `survey_templates` · `survey_sends` 표). **운영 DB에는 직접 적용하세요(배포 체크리스트 참고, 자동 적용되지 않아요).**
- 선택 환경변수: `CAMPTEAM_SURVEY_DAILY_CAP`(기본 300) · `CAMPTEAM_SURVEY_CHUNK`(한 번에 보내는 수, 기본 100) · `CAMPTEAM_HASH_SALT`(번호 해시용 비밀 문자열, 없으면 `ADMIN_PASSWORD` 를 씀).
- AI 영어 채우기: 기존 신청서 AI 채우기와 같은 방식(`ANTHROPIC_API_KEY`), 한도는 루미와 같은 한 곳(`campteamLimits.js`), 기록 이름 `ai_survey`(글 내용은 기록하지 않고 칸 수만 남김). 연락처·금액처럼 보이는 문구는 AI 에 보내지 않고 건너뜀.
- 개인정보: 전화번호·이름은 AI·기록(audit/console)에 넣지 않아요. `survey_sends` 에는 번호의 해시, 보낸 시각, 상태(pending/sent/failed)만 있어요. 홈페이지 신청(CAMP_KV)은 읽기만 해요.
- 권한: 설문 보내기(미리보기 포함)·템플릿 저장/삭제·AI 채우기는 캠프 영역 **수정** 권한이 있는 캠프팀원만. 보기만 가능한 팀원은 설문 목록(개수)과 템플릿 불러오기만 가능.
- 예전 설문(별점·선택·글)은 그대로 열리고 답을 받고 결과를 보여 줘요(`audience` 는 「기타」로 취급).
