# 아침 확인 가이드 (5~10분)

배포·push는 **하지 않았습니다.** 아래는 전부 내 컴퓨터 안에서만 도는 가짜(더미) 데이터 확인입니다.

## 0. 먼저 알아둘 것
- 실제 작업 폴더: `~/wolko-camp-team-work/wolko-website`
  (Documents 폴더가 iCloud 동기화 때문에 빌드가 멈춰서 옮겼고, `Documents/wolko-camp-team/wolko-website` 는 그쪽으로 가는 바로가기입니다.)
- 브랜치: `feature/camp-team-portal` (로컬 커밋만, 원격에 올리지 않음)

## 1. 실행
터미널에서:
```bash
cd ~/wolko-camp-team-work/wolko-website && ./camp-team/dev/run-local.sh
```
처음엔 빌드 때문에 1~2분 걸립니다. "Ready on http://localhost:8788" 이 나오면 브라우저에서:

- **http://localhost:8788/dev-login/** → 역할을 고르면 그 계정으로 로그인됩니다(개발용 페이지, 운영에는 없음)
- 멈추려면 터미널에서 `Ctrl + C`
- 처음 상태로 되돌리려면 `camp-team/dev/.state` 폴더를 지우고 다시 실행

## 2. 역할별로 볼 것 (http://localhost:8788/dev-login/ 에서 고르기)
| 역할 | 확인 포인트 |
|---|---|
| 관리자 | 모든 것 + 팀 명단·설정·TV·변경 기록 |
| **캠프팀 디렉터** / **캠프 재정 담당** | **둘이 같은 권한**: 장부·엑셀 가져오기·경비 연동·계산기·기간 마감까지 모두. (재정 담당도 일반 업무 작성 가능) |
| **월코 재정 담당(조회)** | 예산 메뉴의 모든 탭을 **보기만** — 수정·추가·가져오기 버튼이 없음 |
| 캠프팀 팀원 | 일반 자료는 작성, 예산은 **조회만** |
| 그 외 월코 팀(명단 밖, dev-login 맨 아래 계정) | **캠프 목록 · 신청 인원 숫자 · 「월코 팀 전체 공개」 파일만**. 업무·회의·결정·예산·개인정보·특이사항·팀 공지는 없음 (API도 403) |

## 3. 화면별 5분 체크리스트
1. **홈** — 진행 중/마감 지남/담당 미정 숫자, 다가오는 일정, 최근 결정, 공지
   - **홈 꾸미기**(넓은 화면): 위젯 위쪽 줄을 끌어 옮기고, 오른쪽 아래 모서리를 끌어 크기 조절, 눈 아이콘(숨김), ↔(전체/반쪽), ✕(빼기). **위젯 추가**로 공지·바로가기·내 담당 업무·달력·D-day·변경 기록(관리자만)을 넣고, **빈틈 정리**로 빈 공간을 위로 모음. 위젯을 끌고 화면 위·아래 끝으로 가면 자동 스크롤됨. 폰에서도 "홈 꾸미기"가 되고 화살표(▲▼)로 순서를 바꿈. 달력 위젯은 "달력/목록" 전환. **최근 변경 기록**은 캠프팀 팀원 모두가 봄(팀원 계정으로 확인). 관리자는 위쪽 "모두의 기본 홈"으로 모두에게 적용. 겹치게 놓으면 원래 자리로 돌아감. 21:9처럼 아주 넓은 창에서도 오른쪽 빈 여백 없이 꽉 참
   - **팝업 확인**: 캠프별 공간 → "+ 행사" → 이름을 입력하고 바깥 배경을 눌러 "저장하고 닫기 / 저장 안 하고 닫기 / 계속 편집" 확인. ✕·Esc도 같음. 아무것도 안 고쳤으면 바로 닫힘
   - **왼쪽 메뉴**: 포털과 같은 색·모양, 메뉴마다 선 아이콘. 폰 폭에서는 오른쪽 위 햄버거(☰)로 메뉴가 오른쪽에서 열림. **📚 캠프 자료실**을 눌러 "← 캠프팀으로 돌아가기" 막대 확인(로컬에서는 자료 저장소가 없어 목록이 비어 보이는 게 정상)
2. **캠프** → 캠프 카드의 **공간** 버튼 — 한 캠프의 일정·업무·회의·결정·파일·예산이 한 화면에
3. **업무 / 달력** — 업무: 목록·체크리스트 템플릿·시트에서 가져오기. **달력**(새 메뉴): 위에 월 달력, 아래에 고른 날의 일정 목록, 달력/목록 전환, 일정 추가. 업무: "마감 지남 · 담당 없음" 필터, 담당·기한 빈 채로 저장, 체크리스트 템플릿 적용 미리보기(마감일 자동 계산, 담당자는 제안만)
4. **회의** — 회의 하나 열어 한/영 나란히 보기, 안건별 논의, 결정 이력(새 결정이 이전 것을 "대체됨"으로 남김), 업무 만들기(두 번 눌러도 한 번만 생성)
5. **자료** — 더미 파일 업로드, 새 버전 올리기·되돌리기, 외부 링크 등록, 여러 캠프에 연결, 검색
6. **검색**(왼쪽 위 검색창) — 업무·회의·결정·파일을 한꺼번에
7. **예산**(관리자/재정/팀원) — 항목, 분류별 합계, 예상 리포트, 지난 캠프 복사, CSV 내려받기
8. **TV 편집**(관리자) → 위젯 끌어서 배치 → 저장 → "TV 열기" 로 `/tv/?t=…` 확인. 시안용 열쇠는 `testtoken1` (더미 시드 전용)
9. **설정**(관리자) — 명단, 내보내기, 변경 기록, 용어집, (켜지지 않은) 구글 연동 상태 표시
10. **폰/아이패드 폭**으로 줄여서 가로 스크롤이 없는지

### 캠프 예산 · 회계 장부 둘러보기 (디렉터 또는 캠프 재정 담당으로 로그인)
1. 왼쪽 **캠프 예산** → 기간 선택(가짜 "2027 상반기")이 열려요.
2. **요약**: 이월금·수입·지출·현재 잔액, 항목별 "예산 대비 실제", 월별 흐름.
3. **장부**: 맨 위 "빠른 입력"으로 거래 한 줄 넣어 보기(날짜·구분·항목·금액). 줄마다 잔액이 계산돼요.
4. **엑셀 가져오기**: 엑셀 파일(.xlsx)을 올리면 "새 줄 / 바뀐 줄 / 파일에 없는 줄 / 그대로"를 미리 보여 줘요. 같은 파일을 다시 올려 보면 "바뀐 것이 없어요". 장부 화면의 **엑셀로 내려받기**로 받은 파일을 고쳐서 다시 올려도 정확히 같은 줄로 인식돼요.
5. **경비 연동**: "캠프 계좌"로 볼 출금 계좌(예: Junior Camp)를 고르고 저장 → 가짜 경비 리포트 중 송금 완료분이 지출로 들어와요. 장부와 비슷한 거래가 있으면 "같은 거래예요(연결만)"로 중복을 막아요.
6. **잔액 대조**: 통장 잔액을 적으면 장부 잔액과의 차이를 기록해요(포털은 은행에 접속하지 않아요).
7. **계산기**: 식비는 「1끼 단가 × 인원 × 끼니 수」 — 식사 일정 카드에서 첫 끼니·마지막 끼니를 고르면 날짜별 끼니 표가 만들어지고, 칸을 눌러 넣고 뺄 수 있어요(2박 3일 첫날 점심~마지막 날 점심 = 7끼). 줄마다 계산식(예: 80,000원 × 60명 = 4,800,000원)이 바로 보이고, 캠프비 인원 합계가 캠퍼 수와 맞는지 알려 줘요. 예상 남는 금액·필요한 평균 캠프비, 저장·비교·「기간 예산에 적용」. 화면 맨 위에는 항상 **캠프 통장 잔액(장부 기준)** 이 보이고, 「캠프별 예산안」 화면에는 「← 회계 장부로 돌아가기」가 있어요. 쉬운 설명서: `camp-team/FINANCE-GUIDE.md`.
8. **기간 · 마감**: 6개월/분기 프리셋으로 새 기간 → 마감하기(다음 기간 선택 또는 새로 만들기) → 다음 기간에 「이월금」이 자동으로 생기고, 마감된 기간은 잠겨요. 다시 열면 이월금이 거둬져요.

### 캠프별 공간 · 포털 신청 현황 (디렉터 또는 캠프 재정 담당으로 로그인)
1. 「캠프별 공간」→ 캠프(예: 2027 Winter Camp) 를 열면 맨 위에 **신청 현황 · 참가자 · 예산** 카드가 있어요. (로컬에는 가짜 신청 자료가 들어 있어요.)
2. 세 가지 숫자: **확정만 / 예약금 수납 이상(홈페이지 게이지와 같은 기준) / 신청한 사람 전부**. 예약금 수납 이상 칸에는 완납 몇 명·예약금만 몇 명·남은 잔금, 맨 아래에 대기(예비) 명단이 따로 보여요.
3. 「이 인원으로 예산 계산하기」→ 계산기에서 「신청 현황 불러오기」를 누르면 캠퍼 수와 캠프비 줄(얼리버드·할인별로 나뉨)이 채워져요. 지출은 그대로라서 바로 남는 금액을 볼 수 있어요.
4. 캠퍼 명단·스태프 지원 현황은 눌러서 펼쳐요. 디렉터·캠프 재정·관리자는 줄을 눌러 연락처·환불 계좌 등을 볼 수 있고(조회 기록이 남아요), 일반 팀원·월코 재정 담당은 이름·학년·특이사항까지만 보여요.
5. 연결: 「연결 변경」에서 포털 캠프를 고르거나 ID 를 직접 입력해요. 포털에 아직 없는 미래 캠프는 연결 없이 두면 돼요.
6. 이 화면은 **읽기만** 해요. 포털 신청 자료를 고치거나 캠프팀 DB 에 복사하지 않아요.

### 알림공지 · 오늘 할 일 · 주간 이메일 (팀원 계정으로 로그인 → 홈)
1. 홈 맨 위 **「오늘 내가 할 일」**: 마감 지난 일 / 오늘 마감 / 곧 마감 / 오늘·내일 회의와 일정 / 새 결정. 업무 옆 「완료」를 누르면 바로 완료 처리돼요. (내 이메일이 담당자로 지정된 업무만 나와요.)
2. 왼쪽 메뉴 **알림공지**(빨간 숫자)와 위쪽 **종 아이콘**: 누르면 오른쪽에서 패널이 열려요. 알림은 ✕로 끄거나 「확인」으로 읽음 표시.
3. 알림공지 화면 **내 알림 / 팀 공지** 탭. 팀 공지는 **+ 새 공지**로 팀 전체 또는 선택한 사람에게 올려요. 올린 사람·관리자만 고치고 지울 수 있고, 지워도 휴지통에서 복구돼요.
4. 오른쪽 「내 설정」에서 **주간 이메일**(매주 화요일 오전)을 끌 수 있고, 관리자는 「알림 기준」(마감 3일·1일 전 등)을 바꿔요.
5. AI 한두 줄 요약은 `ANTHROPIC_API_KEY` 가 있을 때만 나와요(로컬에는 없음). 목록은 AI 없이도 정확히 나와요.

### 항목별 권한 (관리자 계정 → 설정)
- 팀 명단의 사람 옆 **권한** 버튼 → 일정·업무 / 회의록·결정 / 자료실 / 캠프별 공간·공지 / 예산·장부 / 신청자 개인정보 / 팀 공지 쓰기를 **「안 보임 · 보기만 · 수정 가능」** 으로 고르는 표. 역할 기본값과 다른 칸만 따로 저장돼요. 「역할 기본값으로 되돌리기」도 있어요.
- 관리자(고정 관리자 포함)의 권한은 바꿀 수 없어요. 권한 설정은 관리자만 볼 수 있고 바꿀 수 있어요.
- 「안 보임」으로 하면 메뉴가 사라지고, 주소를 직접 입력해도 서버가 막아요. 홈·검색·달력·알림에서도 그 영역 내용이 빠져요.

### 캠프 공간 · 장부 화면 정리
- 캠프 공간 맨 위는 **한 줄 요약 띠**(신청 인원 · 예상 수입 · 계획 지출 · 남을 돈)예요. 「자세히 보기」로 전체 신청 현황이 펼쳐지고, **화면 편집**으로 카드 순서를 바꾸거나 숨겨요(내 화면만).
- 캠프 예산: 기간 선택이 위쪽 줄로 옮겨졌고, 탭은 **요약 · 장부 · 기간 · 마감 · 기간 예산 + ⋯ 더보기**(엑셀 가져오기, 경비 연동, 잔액 대조, 계산기, 항목 목록, 캠프별 예산안).
- 헷갈릴 만한 곳 옆에는 **「?」**: 마우스를 올리면(폰은 누르면) 안내가 나와요.

### 이번 수정 묶음 — 새로 볼 것 (자세한 배포 확인은 `DEPLOY-CHECKLIST.md` D-4)
- 설정 → 팀 명단 → **수정**: 이름·「업무에 적는 이름(별칭)」 변경. 업무 담당자는 명단에서 고르거나 이름/별칭을 손으로 적어도 인식(알림·오늘 할 일·주간 메일).
- **캠프별 공간**: 카드를 끌어 순서 바꾸기(내 계정만 저장 / 관리자는 모두의 기본). 폰에서는 카드형 목록.
- **자료실**: 넓은 업로드 영역, 끌어다 놓기, 파일 열기 버튼, 「월코 팀 전체 공개」 체크.
- 팝업 뒤 흐림(왼쪽 메뉴 선명), 링크 스타일, 폰 표→카드, 폰 헤더 언어 버튼, `?` 풍선 위치.

## 4. 자동 점검 (선택)
```bash
node camp-team/dev/predeploy-check.mjs
```
확인하는 것: ① 기존 파일은 그대로(추가된 파일만) ② 루트 `wrangler.toml` 없음 ③ 개발용 우회 코드 격리 ④ 실제 이름·비밀값 검사 ⑤ 캠프팀 테스트 172개 ⑥ 빌드 결과에 캠프팀/TV 페이지 생성. 마지막에 `✅ 모든 점검 통과` 가 나오면 정상입니다.
(원래 있던 테스트 중 5건은 원본에서도 실패하는 것이라 "참고용"으로만 표시합니다.)

## 5. 결정해 주실 것
1. 화면 확인 후 **수정하고 싶은 것** 알려 주세요 (문구·배치·기능).
2. **포털 메뉴 카드** (`camp-team/deploy/portal-menu.patch`) — 포털 "CAMP" 구역의 캠프 자료실 아래에 "캠프팀" 카드(포털 로그인한 모두에게 보임). 배포 직전에 적용할지.
3. 배포 시점과 순서 → `DEPLOY-CHECKLIST.md`.

## 6. 알아둘 점
- `node_modules` 에는 맥용 도구 설치로 생긴 변경이 working tree 에만 있습니다(커밋 안 함, 원본 코드 아님). 필요하면 `git checkout -- node_modules` 로 되돌릴 수 있지만 그러면 로컬 빌드가 안 돌아갈 수 있습니다.
- `public/images/uploads/` 아래의 추적되지 않은 사진 파일들은 이 작업과 무관하게 이미 있던 것으로, 건드리거나 커밋하지 않았습니다.
