# 아침 확인 가이드 (5~10분)

배포·push는 **하지 않았습니다.** 아래는 전부 내 컴퓨터 안에서만 도는 가짜(더미) 데이터 확인입니다.

## 0. 먼저 알아둘 것
- 실제 작업 폴더: `~/wolko-camp-team-work/wolko-website`
  (Documents 폴더가 iCloud 동기화 때문에 빌드가 멈춰서 옮겼고, `Documents/wolko-camp-team/wolko-website` 는 그쪽으로 가는 바로가기입니다.)
- 브랜치: `feature/camp-team-portal` (로컬 커밋만, 원격에 올리지 않음)

## 1. 실행
터미널에서:
```bash
cd ~/wolko-camp-team-work/wolko-website && ./camp-team/dev/run-local.sh
```
처음엔 빌드 때문에 1~2분 걸립니다. "Ready on http://localhost:8788" 이 나오면 브라우저에서:

- **http://localhost:8788/dev-login/** → 역할을 고르면 그 계정으로 로그인됩니다(개발용 페이지, 운영에는 없음)
- 멈추려면 터미널에서 `Ctrl + C`
- 처음 상태로 되돌리려면 `camp-team/dev/.state` 폴더를 지우고 다시 실행

## 2. 역할별로 볼 것
| 역할 | 확인 포인트 |
|---|---|
| 관리자 | 왼쪽 메뉴에 **예산·휴지통·설정**이 보임. 설정에서 명단/TV 열쇠/내보내기/변경 기록/용어집 |
| 재정 담당 | **예산** 보임, 업무·자료 작성 버튼은 없음(조회만) |
| 캠프팀 팀원 | 업무·회의·자료 작성 가능, 예산 보임 |
| 그 외 사용자 | **예산 메뉴 없음**, 금액·금액 파일 없음, 작성 버튼 없음 |

## 3. 화면별 5분 체크리스트
1. **홈** — 진행 중/마감 지남/담당 미정 숫자, 다가오는 일정, 최근 결정, 공지
   - **✏️ 홈 꾸미기**: 섹션 끌어서 순서 바꾸기, ▲▼, 🙈(숨김), ◧/▭(너비), 저장. 관리자는 위쪽 "모두의 기본 홈"으로 바꿔 모두에게 적용하고, "기본 홈으로 되돌리기"로 내 설정 해제
   - **팝업 확인**: 캠프별 공간 → "+ 행사" → 이름을 입력하고 바깥 배경을 눌러 "저장하고 닫기 / 저장 안 하고 닫기 / 계속 편집" 확인. ✕·Esc도 같음. 아무것도 안 고쳤으면 바로 닫힘
   - **왼쪽 메뉴**: 포털과 같은 색·모양, 메뉴마다 선 아이콘. **📚 캠프 자료실**을 눌러 "← 캠프팀으로 돌아가기" 막대 확인(로컬에서는 자료 저장소가 없어 목록이 비어 보이는 게 정상)
2. **캠프** → 캠프 카드의 **공간** 버튼 — 한 캠프의 일정·업무·회의·결정·파일·예산이 한 화면에
3. **업무** — 목록/달력 전환, "마감 지남 · 담당 없음" 필터, 담당·기한 빈 채로 저장, 체크리스트 템플릿 적용 미리보기(마감일 자동 계산, 담당자는 제안만)
4. **회의** — 회의 하나 열어 한/영 나란히 보기, 안건별 논의, 결정 이력(새 결정이 이전 것을 "대체됨"으로 남김), 업무 만들기(두 번 눌러도 한 번만 생성)
5. **자료** — 더미 파일 업로드, 새 버전 올리기·되돌리기, 외부 링크 등록, 여러 캠프에 연결, 검색
6. **검색**(왼쪽 위 검색창) — 업무·회의·결정·파일을 한꺼번에
7. **예산**(관리자/재정/팀원) — 항목, 분류별 합계, 예상 리포트, 지난 캠프 복사, CSV 내려받기
8. **TV 편집**(관리자) → 위젯 끌어서 배치 → 저장 → "TV 열기" 로 `/tv/?t=…` 확인. 시안용 열쇠는 `testtoken1` (더미 시드 전용)
9. **설정**(관리자) — 명단, 내보내기, 변경 기록, 용어집, (켜지지 않은) 구글 연동 상태 표시
10. **폰/아이패드 폭**으로 줄여서 가로 스크롤이 없는지

## 4. 자동 점검 (선택)
```bash
node camp-team/dev/predeploy-check.mjs
```
확인하는 것: ① 기존 파일은 그대로(추가된 파일만) ② 루트 `wrangler.toml` 없음 ③ 개발용 우회 코드 격리 ④ 실제 이름·비밀값 검사 ⑤ 캠프팀 테스트 91개 ⑥ 빌드 결과에 캠프팀/TV 페이지 생성. 마지막에 `✅ 모든 점검 통과` 가 나오면 정상입니다.
(원래 있던 테스트 중 5건은 원본에서도 실패하는 것이라 "참고용"으로만 표시합니다.)

## 5. 결정해 주실 것
1. 화면 확인 후 **수정하고 싶은 것** 알려 주세요 (문구·배치·기능).
2. **포털 메뉴 카드** (`camp-team/deploy/portal-menu.patch`) — 포털 "CAMP" 구역의 캠프 자료실 아래에 "캠프팀" 카드(포털 로그인한 모두에게 보임). 배포 직전에 적용할지.
3. 배포 시점과 순서 → `DEPLOY-CHECKLIST.md`.
4. 재정 담당·팀원 이메일(배포 후 설정 화면에서 직접 입력).
5. 실제 체크리스트 템플릿(배포 후 붙여넣기 가져오기로 넣으면 됨).

## 6. 알아둘 점
- `node_modules` 에는 맥용 도구 설치로 생긴 변경이 working tree 에만 있습니다(커밋 안 함, 원본 코드 아님). 필요하면 `git checkout -- node_modules` 로 되돌릴 수 있지만 그러면 로컬 빌드가 안 돌아갈 수 있습니다.
- `public/images/uploads/` 아래의 추적되지 않은 사진 파일들은 이 작업과 무관하게 이미 있던 것으로, 건드리거나 커밋하지 않았습니다.
