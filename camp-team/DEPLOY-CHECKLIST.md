4. **엑셀 가져오기**: 재정 담당의 실제 엑셀 파일을 올려 "비교하기"로 먼저 미리 보세요(이 단계는 아무것도 저장하지 않아요). 괜찮으면 적용. 엑셀의 첫 「이월금」 줄은 첫 기간에는 그대로 가져오고, 이전 기간에서 자동으로 넘어온 이월금이 이미 있으면 기본으로 건너뛰어요(이중 계산 방지). 이후 주 1회/월 1회 새 파일을 올리면 바뀐 줄만 반영돼요.
5. **경비 연동**: 캠프 계좌(예: Junior Camp 주니어캠프)에 체크, 경비 카테고리→장부 항목 규칙을 정하고 저장 → "지금 가져오기". 처음 며칠은 「확인이 필요한 항목」을 사람이 보면서 규칙을 익혀 가세요. (이 기능은 기존 경비 리포트를 **읽기만** 하고 새 설정이 필요 없어요 — 이미 있는 CAMP_KV 바인딩을 씁니다)
6. 월코 재정 담당에게 통장 잔액을 받아 **잔액 대조**에 한 번 기록해 보세요.

## E. 선택 기능 (필요할 때, 하나씩, 복사본으로 먼저)
| 기능 | 순서 |
|---|---|
| **Sheets 미러링** | ① **복사본 시트**를 만들고 `Task ID` 열 추가 ② 서비스 계정에 복사본 편집 권한 ③ `CAMPTEAM_SHEET_ID`(복사본) 설정 ④ 설정 화면 **미리보기**로 "무엇을 쓸지" 확인 ⑤ `CAMPTEAM_SHEETS_WRITE=1` + 관리자 확인으로 복사본에 쓰기 ⑥ 문제 없으면 운영 시트 ID 로 교체. 기존 `Task ID` 없는 줄은 건드리지 않고, 줄 삭제는 하지 않음 |
| **Calendar** | 테스트 캘린더 → 서비스 계정에 공유 → `CAMPTEAM_CALENDAR_ID` → 미리보기 → `CAMPTEAM_CALENDAR_WRITE=1` |
| **Google 로그인** | Google Cloud 에서 OAuth 클라이언트(웹) 만들기 → 승인된 JavaScript 출처에 사이트 주소 → `CAMPTEAM_GOOGLE_CLIENT_ID` 설정. wolko.org 계정만, 조회 전용 |
| **AI 초안** | `ANTHROPIC_API_KEY` 를 **비밀(Secret)** 로 추가. 사용량 과금 주의. 키는 채팅에 붙여넣지 말 것 |

## F. 문제가 생기면 (되돌리기)
- **캠프팀 전체 끄기**: Pages 바인딩의 `DB` 를 제거하면 캠프팀 API 는 오류 안내를 내고, 기존 포털은 영향 없음(독립 경로 `/campteam/*`, `/api/campteam/*`, `/tv/`)
- **포털 메뉴 카드만 제거**: `git apply -R camp-team/deploy/portal-menu.patch`
- **TV**: TV Bro 주소를 기존 대시보드 주소로 되돌리면 끝
- **TV 열쇠 유출 의심**: TV 편집 → 열쇠 다시 만들기(이전 주소 즉시 무효)
- **데이터 백업**: 설정 → 내보내기(JSON 전체/CSV). 배포 후 주기적으로 받아 두기
- **잘못 삭제**: 휴지통에서 복구(영구 삭제 기능 없음)

## G. 비밀값 안전 수칙
- API 키·서비스 계정 JSON·토큰은 **대시보드의 비밀 칸에만** 입력. 채팅, 저장소, 문서에 붙여넣지 않습니다.
- 저장소는 공개이므로 실제 이름·연락처·내부 문서를 올리지 않습니다(`predeploy-check` 가 일부 검사).

## D-22. 캠프 준비 — 진행표 · 준비물 · 연락처 · 반복 캠프 · 폰 캘린더 · 이름 자동 완성 (DB: 0027)

## D-23. 캠프 시작·마감 마법사 · 평가 설문 (DB: 0028 surveys, survey_responses)
- [ ] **DB 먼저**: 0028 적용(새 표 2개).
- [ ] 캠프 준비 화면에 탭 3개가 늘었다: 시작 마법사 / 마감 마법사 / 평가 설문 (위에서 캠프를 고른다).
- [ ] 시작 마법사: 새 캠프를 고르면 지난 캠프 후보(비슷한 순서)가 나오고 「루미에게 추천받기」로 3개를 추천받는다(AI 꺼져 있으면 비슷한 순서 안내). 후보를 고르면 업무·진행표·준비물·자료가 체크 목록으로 나오고, **체크한 것만** 복사된다. 담당자는 비어 있고 날짜는 시작일 차이만큼 옮겨진다. 두 번 눌러도 중복되지 않는다. 시작 날짜가 없으면 진행표는 건너뛰고 안내한다.

## D-29. 캠프 준비 「신청서」 탭 — 다음 캠프 신청서·스태프/크루 지원서 만들기 (DB: 0032 camp_form_roles · camp_forms · camp_form_approvals)

## D-32. 설문 만들기(구글 폼 방식) · 대상별 알림톡 보내기 (DB: 0034 survey builder)

## D-35. 알림 설정 개편 — 설정 팝오버 · 사람별 알림 시점 · 고정 알림 · 이메일 스위치 · 그만 받기 링크 (DB: 0037 alert_prefs)
- **DB**: `camp-team/db/0037_alert_prefs.sql` 한 번 실행 — `notify_prefs` 에 칸만 덧붙인다(dueDays·eventDays·emailDue·quietStart·quietEnd·notifyMine, 기존 행·값은 그대로, 채울 것 없음). 마이그레이션 전에 코드가 먼저 배포돼도 새 칸이 없으면 기본값으로 동작하고 알림은 열린다(설정을 저장할 때만 오류).
- **새 비밀값 없음**: 「이 메일 그만 받기」 서명 링크는 기존 `ADMIN_PASSWORD` 에 목적 이름(`campteam-email-off:v1`)을 붙인 HMAC 키로 만든다. 링크는 400일 동안 쓸 수 있고, 로그인 토큰으로는 만들 수 없다.
- **화면**: 알림 화면은 목록만 가득 보이고, 오른쪽 위 「설정」을 누르면 버튼 바로 밑에 팝오버(폰에서는 아래에서 올라오는 시트)가 열린다. 업무 마감·회의·일정은 한 줄 요약(예: 「3일 전, 1일 전」)을 눌러 체크 목록으로 고른다(직접 입력 1~60일, 최대 8개). 관리자 「고정 알림」에 있는 날은 모두에게 켜져 있고 「고정 알림으로 이미 설정됨」으로 잠겨 보인다. 당일·마감이 지난 뒤는 늘 알린다.
- **규칙**: 알림 일수 = 팀 고정 알림 ∪ 내가 더한 날(합집합, 같은 날은 알림 한 번). 아무것도 정하지 않은 사람은 예전과 똑같이 업무 3일·1일 전, 일정 1일 전. 「내가 만든 업무도 알림 받기」를 켠 사람은 담당자가 달라도 같은 규칙으로 받는다(목록에 「내가 만든 업무 → 담당자」로 표시).
- **이메일**: 지금 실제로 나가는 메일은 **매주 화요일 이메일 하나**뿐이다(마감·일정 알림 메일은 아직 없다). 「마감·일정 알림 이메일」 스위치는 값만 저장해 두었다가 그 메일이 생기면 따른다(「그만 받기」 링크는 이 스위치도 함께 끈다). 이메일을 꺼도 알림 목록은 그대로이고, 알림은 사람이 확인·✕ 를 눌러야 사라진다.
- **방해 금지 시간대**(한국 시간, 예: 22:00~07:00): 걸린 사람은 그 실행에서 주간 메일을 건너뛴다(발송 기록을 남기지 않음). 주간 메일 스케줄에 **오후 3시(한국) 실행을 하나 더** 넣었다(`.github/workflows/campteam-weekly-mail.yml`, cron `0 6 * * 2`) — 오전에 걸렸거나 실패한 사람만 보내고, 이미 받은 사람은 발송 기록으로 건너뛴다. 강제 발송(force)에도 적용되고 `?to=` 시험 발송은 제외.
- **모든 메일 맨 아래**(`sendCampMail`): 「알림 → 설정에서 끌 수 있어요」 + 「이 메일 그만 받기」 링크(로그인 없이 `/api/campteam/email-off?t=…` → 매주·마감 이메일 둘 다 즉시 끄고 `/portal/campteam/email-off/` 확인 화면). 받은편지함의 「구독 취소」 단추(List-Unsubscribe, 한 번 누르면 꺼짐)도 같은 주소. 틀리거나 만료된 링크는 아무것도 바꾸지 않고 안내 화면. ※ 일부 메일 보안 프로그램이 링크를 미리 열어 보면 꺼질 수 있어서, 확인 화면에 「실수였나요? 다시 받기」 단추를 뒀다.
- **나에게 테스트 이메일 보내기**: 1시간에 3번(실패 포함), 요청한 사람에게만 한 통(`mail_log` kind='test').
- 확인: ① 알림 → 설정 → 업무 마감 「2일 전」 체크 → 요약에 반영, 관리자 「고정 알림」에서 7일 전 추가·저장 → 일반 팀원 화면에서 「고정 알림으로 이미 설정됨」 ② 팀원 계정으로 고정 알림 저장 시 거부 ③ 「나에게 테스트 이메일 보내기」 → 받은 메일 맨 아래 「이 메일 그만 받기」 → 확인 화면, 알림 설정에서 두 스위치가 꺼짐 ④ 로그아웃한 브라우저(또는 휴대폰)에서도 같은 링크가 열림 ⑤ 엉뚱한 링크(글자 하나 바꿈)는 「쓸 수 없어요」 화면 ⑥ 폰에서 설정이 아래 시트로 열리고 가로 스크롤이 없음.
