## D-1. 회계 장부 첫 설정 (배포 후, 관리자로)

2. **캠프 예산 → 항목 목록**: 기본으로 엑셀 「목록」 탭과 같은 항목이 들어 있어요. 필요하면 추가·이름 변경·"사용 안 함".

4. **엑셀 가져오기**: 재정 담당의 실제 엑셀 파일을 올려 "비교하기"로 먼저 미리 보세요(이 단계는 아무것도 저장하지 않아요). 괜찮으면 적용. 엑셀의 첫 「이월금」 줄은 첫 기간에는 그대로 가져오고, 이전 기간에서 자동으로 넘어온 이월금이 이미 있으면 기본으로 건너뛰어요(이중 계산 방지). 이후 주 1회/월 1회 새 파일을 올리면 바뀐 줄만 반영돼요.
5. **경비 연동**: 캠프 계좌(예: Junior Camp 주니어캠프)에 체크, 경비 카테고리→장부 항목 규칙을 정하고 저장 → "지금 가져오기". 처음 며칠은 「확인이 필요한 항목」을 사람이 보면서 규칙을 익혀 가세요. (이 기능은 기존 경비 리포트를 **읽기만** 하고 새 설정이 필요 없어요 — 이미 있는 CAMP_KV 바인딩을 씁니다)
6. 월코 재정 담당에게 통장 잔액을 받아 **잔액 대조**에 한 번 기록해 보세요.

## E. 선택 기능 (필요할 때, 하나씩, 복사본으로 먼저)
| 기능 | 순서 |
|---|---|
| **Sheets 미러링** | ① **복사본 시트**를 만들고 `Task ID` 열 추가 ② 서비스 계정에 복사본 편집 권한 ③ `CAMPTEAM_SHEET_ID`(복사본) 설정 ④ 설정 화면 **미리보기**로 "무엇을 쓸지" 확인 ⑤ `CAMPTEAM_SHEETS_WRITE=1` + 관리자 확인으로 복사본에 쓰기 ⑥ 문제 없으면 운영 시트 ID 로 교체. 기존 `Task ID` 없는 줄은 건드리지 않고, 줄 삭제는 하지 않음 |
| **Calendar** | 테스트 캘린더 → 서비스 계정에 공유 → `CAMPTEAM_CALENDAR_ID` → 미리보기 → `CAMPTEAM_CALENDAR_WRITE=1` |
| **Google 로그인** | Google Cloud 에서 OAuth 클라이언트(웹) 만들기 → 승인된 JavaScript 출처에 사이트 주소 → `CAMPTEAM_GOOGLE_CLIENT_ID` 설정. wolko.org 계정만, 조회 전용 |
| **AI 초안** | `ANTHROPIC_API_KEY` 를 **비밀(Secret)** 로 추가. 사용량 과금 주의. 키는 채팅에 붙여넣지 말 것 |

## F. 문제가 생기면 (되돌리기)
- **캠프팀 전체 끄기**: Pages 바인딩의 `DB` 를 제거하면 캠프팀 API 는 오류 안내를 내고, 기존 포털은 영향 없음(독립 경로 `/campteam/*`, `/api/campteam/*`, `/tv/`)
- **포털 메뉴 카드만 제거**: `git apply -R camp-team/deploy/portal-menu.patch`
- **TV**: TV Bro 주소를 기존 대시보드 주소로 되돌리면 끝
- **TV 열쇠 유출 의심**: TV 편집 → 열쇠 다시 만들기(이전 주소 즉시 무효)
- **데이터 백업**: 설정 → 내보내기(JSON 전체/CSV). 배포 후 주기적으로 받아 두기
- **잘못 삭제**: 휴지통에서 복구(영구 삭제 기능 없음)

## G. 비밀값 안전 수칙
- API 키·서비스 계정 JSON·토큰은 **대시보드의 비밀 칸에만** 입력. 채팅, 저장소, 문서에 붙여넣지 않습니다.
- 저장소는 공개이므로 실제 이름·연락처·내부 문서를 올리지 않습니다(`predeploy-check` 가 일부 검사).

- TV 편집기 정리(같은 묶음): DB 변경 없음. 「TV 설정」에서 **「색 테마」를 없앴다** — TV 와 편집 미리보기는 항상 진한 청록이고, 예전에 「밝은 화면」으로 저장해 둔 값은 무시된다. 「하늘 배경」 켜기/끄기는 그대로 남는다. 편집 화면 오른쪽 설정 칸은 미리보기 높이까지만 커지고 넘치면 그 안에서 스크롤한다. TV 프로그램 버전이 `1.1.1` 로 올라가서 TV 가 켜져 있으면 알아서 새로고침한다. 확인: TV 대시보드 → 위젯을 눌러도 아래 「TV 설정」이 크게 밀려나지 않음, 「TV 설정」에 색 테마 칸이 없음.

## D-13. AI 추천 (자료 올릴 때 제목·설명·종류·캠프 채우기, 행사 이름 추천)
- DB 변경 없음. 새 API `/api/campteam/ai-suggest`(저장하지 않고 **제안만** 돌려줌), 새 화면 파일 `doc-text.js`(브라우저에서 파일 글을 꺼냄).
- 서버에 `ANTHROPIC_API_KEY`(번역에 이미 쓰는 키)가 있어야 켜진다. 없으면 화면에 「AI 추천이 아직 켜지지 않았어요」가 보이고 버튼은 꺼져 있다. 키는 Cloudflare 비밀값에만 둔다.
- 보내는 것: 자료 추가 창에서 **고른 파일 1개**의 앞부분 글(약 4,000자) 또는 PDF(8MB 이하)·사진(줄여서). Word·PowerPoint·Excel 은 브라우저에서 글만 꺼내 보낸다. **예산(금액) 분류는 보내지 않는다.** 폴더·여러 파일 올리기는 예전처럼 이름만 정리한다. 켜기/끄기 스위치는 이 브라우저에 기억된다(기본 꺼짐). 「✨ 추천 받기」 버튼을 누르면 스위치가 꺼져 있어도 그 파일 하나는 보낸다.
- 채워지는 칸에는 「AI」 표시가 붙고, 직접 고치면 표시가 사라지며 이후 추천이 덮어쓰지 않는다. 저장은 직접 누른다. 캠프는 현재 캠프 목록 안에서만 고른다(AI 가 번호를 지어내도 버려짐).
- 행사 이름 추천: 캠프별 공간 → 「개별 행사」 창의 「✨ 이름 추천」(「연도 계절 이름」 형식, 칩을 눌러야 이름 칸이 바뀜).
- 확인: ① 자료 추가 → 파일 1개 선택 → 「✨ 추천 받기」로 제목 칩(한글·English)·설명·종류·주제가 채워지고 「AI」 표시가 붙음 ② 예산 분류를 고르면 「AI에 보내지 않아요」 ③ 「개별 행사」에서 연도·계절 입력 후 「이름 추천」 ④ 사용량(비용)은 파일 1개당 AI 호출 1번.

- [ ] 제목 자동 완성 (D-13 추가분): 「+ 자료 추가」에서 제목만 입력 → ① 제목에 캠프 이름이 있으면 「관련 캠프·행사」가 「자동」 표시와 함께 선택된다 (AI 없이) ② 입력창에 캠프 이름 자동 완성 목록이 뜬다 ③ AI 도우미가 켜져 있으면 입력을 멈춘 뒤 1~2초 안에 한글/English 제목 칩이 나온다 (진짜 Claude 확인) ④ 직접 고른 캠프는 제목을 바꿔도 바뀌지 않는다
