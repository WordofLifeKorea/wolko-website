# 밤샘 작업 기록 (2026-10-22 밤 ~ 10-23 아침)

목표: 요청받은 수정·버그를 모두 끝내고, 아침에 바로 배포할 수 있는 상태로 만든다. **배포·푸시는 하지 않는다** (로컬 커밋만).
이 파일은 진행하면서 계속 갱신한다. 맨 아래 「최종 요약」은 마지막에 채운다.

## 결정된 사항 (사용자 확인 완료)
- 업무 담당자: 팀 명단에서 고르는 입력 + 손으로 써도 이름/별칭으로 인식. 명단에 「업무에 적는 이름(별칭)」 등록. 팀 명단에서 이름 수정 가능.
- 「일정·업무」 → **「업무」**(목록·체크리스트 템플릿·시트에서 가져오기) / **「달력」**(월 달력 + 선택한 날 일정 목록 아래. 기존 달력/목록 전환은 유지, 일정 추가는 달력으로).
- 명단 밖 월코 팀: 캠프 목록·신청 인원 숫자·「월코 팀 전체 공개」로 표시한 파일(포스터 등)만. 업무·회의·결정·장부·개인정보·특이사항·팀 공지는 가림.
- 캠프 카드 순서: 기본은 모두 같게, 바꾼 계정만 자기 순서 기억. 위/아래 버튼 없음.
- 파일 업로드: 넓은 드롭 영역 + 어디서든 끌어다 놓기 + 「파일 열기」 버튼 유지.
- 팝업: 왼쪽 메뉴는 선명, 나머지 블러. 링크 밑줄·보라색 제거. 표는 폰에서 카드형. 폰 헤더에 언어 전환 노출.
- 차량 배정(운전자·탑승자·안전 규칙)은 **이번에 안 함** (메모리에 기록해 둠).

(아래에 한 줄씩 추가)

- [완료] 업무 담당자: 명단 이름·별칭 인식(알림·오늘 할 일·주간 메일·홈), 저장 시 이메일 자동 채움, 명단 이름·별칭 수정 API(고정 관리자 포함), 역할 변경·삭제 시 사람별 권한 정리, people API (서버) — 화면은 다음 단계
- [완료] 명단 밖 월코 팀 범위(캠프 목록·공개 파일·신청 인원 숫자만), 파일 「월코 팀 전체 공개」 API, 특이사항을 개인정보 단계로, 캠프 공간·회의 상세·회의 파일 연결 영역별 가림(검토 High/Medium), 테스트 갱신 — 화면(파일 공개 체크박스)은 다음 단계
